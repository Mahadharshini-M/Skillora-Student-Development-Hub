# Skillora – Learn, Practice, Grow 💜

### A Student Development Hub

Skillora is a platform built with a simple idea in mind: every student's learning journey deserves a place where it can be organized and showcased.

During college, students learn new skills, work on projects, earn certificates, participate in activities, and achieve many milestones. However, these accomplishments are often stored in different places, making them difficult to manage and present together.

Skillora aims to bring these details into one organized space, helping students keep track of their growth and build a professional digital presence.

## 🌟 What is Skillora?

Skillora is a Student Development Hub where students can maintain their profiles, manage their technical skills, showcase projects, organize certificates and achievements, and manage their resumes.

The goal is to make student development easier to track and accomplishments easier to present.

## ✨ Key Features

- **Student Dashboard:** Get an overview of your learning journey and development activities.
- **Profile Management:** Maintain personal information and build your student profile.
- **Skills Matrix:** Add technical skills and update your proficiency levels.
- **Project Management:** Organize and showcase projects completed during your academic journey.
- **Certificates:** Keep your certifications organized in one place.
- **Achievements:** Maintain a record of academic and extracurricular accomplishments.
- **Student Directory:** Explore student profiles through a directory.
- **Public Profile:** Present your skills, projects, and achievements through a profile interface.
- **Resume Management:** Manage your resume and make your professional information accessible.
- **Registration and Login:** Create an account and access your personalized student space.

## 📌 Modules

Skillora consists of 12 main modules:

1. Landing Page
2. Student Registration
3. Student Login
4. Dashboard
5. Profile Management
6. Skills Matrix
7. Projects
8. Certificates
9. Achievements
10. Student Directory
11. Public Profile
12. Resume Management

Each module focuses on a different part of student development while contributing to one centralized platform.

## 🛠️ Technologies Used

- HTML5 – Page structure
- CSS3 – Styling and responsive layouts
- Vanilla JavaScript – Application functionality and interactivity
- LocalStorage – Browser-based account and student data storage
- IndexedDB – Resume PDF storage

## 🚀 Getting Started

Follow these steps to run Skillora on your computer.

**1. Clone the repository**

```bash
git clone https://github.com/Mahadharshini-M/Skillora-Student-Development-Hub.git
```

**2. Open the project folder**

```bash
cd Skillora-Student-Development-Hub
```

**3. Open the project in Visual Studio Code**

```bash
code .
```

**4. Run the application**

Open `index.html` using the VS Code Live Server extension.

The application will open in your browser, where you can explore the available modules.

## 💡 What Makes Skillora Useful?

Skillora brings different aspects of student development together instead of making students maintain their accomplishments across multiple disconnected places.

It provides a structured way to record progress, organize work, and present achievements. It can also help students prepare a more complete picture of their abilities when applying for internships and career opportunities.

## 🔮 Future Improvements

Skillora is currently a frontend-based demonstration. There is plenty of scope to improve it further.

Some of the improvements planned for the future include:

- Backend development using Node.js and Express.js.
- MySQL database integration.
- Secure authentication and authorization.
- Cloud-based document and resume storage.
- Improved student profile sharing.
- More advanced progress tracking and analytics.

## ⚠️ Current Project Limitations

This version uses browser storage to maintain demonstration data. Account and student information are stored in LocalStorage, while resume files are handled through IndexedDB.

As a result, data is limited to the browser and origin where it was saved. It does not currently provide centralized database storage or automatic synchronization between devices.
